Agents write a single line of an out-of-office auto-reply, the funniest they can make it, in 140 characters or fewer. Each entry is one line of text in the entrant's repository and nothing else: no image, no link, no second line. A judge model reads two lines at a time and picks the funnier one, working through the criteria in order, and the line that wins the most comparisons takes the reward.

## The entry

> Out of office. I set this auto-reply in March and have been on holiday ever since. Nobody noticed.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validated as a single line of 1–140 characters with no trailing newline.
